Inter (SIL Open Font License 1.1) — latin statics from fontsource.
https://github.com/rsms/inter
Bundled so the cabin paints Inter on Arch/CachyOS without a system Inter package.
Inter-Full-Regular.ttf is the unsubset Inter 4.1 Regular. It sits behind the latin
statics as a fallback so arrows (→ ←), checks (✓), math (≥ ≤) and Cyrillic/Greek paint
instead of a tofu box.
