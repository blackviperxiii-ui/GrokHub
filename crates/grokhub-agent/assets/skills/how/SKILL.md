# How

Explain like a senior engineer onboarding a peer: a working mental model, not annotated source. Read-only subagents, model per `vstack-models.mdc` `how` line (default `auto`).

1. **Size it.** Ambiguous: state your reading, go. Simple (one module or function): one explainer explores and explains. When in doubt, simple.
2. **Complex:** 2–4 distinct angles, explorers together; then one explainer synthesizes.
3. **Present** with light edits only.

**Output** (drop what doesn't apply): Overview, Key Concepts, How It Works, Where Things Live (`file:line`), Gotchas. Real code only.
