# Prove It Works

Check the real thing: liveness directly, the actual value not a cache, the output not a report. Failed check? Suspect the observation first. Best proof: a rerunnable script; keep its output (**show-me-your-work** for big runs). Prove each install channel the user contrasts before calling it docs-only.
