# Swarm

Only when slices are independent and big enough to pay for fan-out.

**Frame.** Done predicate, report shape. Slices, race (declare `first pass`, `rank all`, or `best-of`), or both. Model per `swarm` line (default `auto`). Own output per writer. Measurement briefs name SHAs and method.

**Fan out** in one message, background. Briefs stand alone: goal, slice, how to verify, report as `PASS`, `ISSUES` (all provable), or `BLOCKED` with evidence. Dropout: continue, note it.

**Aggregate.** Missing SHAs or method: respawn once, then gap (never a pass). Apply the race rule. No raw dumps.

**Report:** one table, issue one-liners, gaps.
