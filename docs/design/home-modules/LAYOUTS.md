# Home Mission Control — layout mockup notes

The four layout PNGs (`layout-default.png`, `edit-home-dialog.png`, `layout-performance.png`, `layout-streamer.png`) were attached in chat but are not on every agent VM. Use this plus `SPEC.md`, Notion card, and `gallery-1`…`gallery-5` (module size variants).

## layout-default — Mission Control (default preset)
- Left rail: Home active. **No chat tab bar** on Home.
- Header: LOADOUT · LOCAL · 0 B SENT · "TUESDAY · SEASON 4" · "Ready up, user." · LVL 14 · GRINDER XP bar.
- Columns (equal height, slide 09): **L** Today's Objectives + Weekly Streak (~5 DAYS) + coach tip · **M** PC Loadout (temps / storage / tune-up) · **S** Up Next cover cards (QUEUED) with ✎ tucked top-right of the module area.
- Chips + chat bar pinned: "Assign an objective or ask anything..." + yellow send.

## edit-home-dialog
- Modal SETTINGS · HOME · "Edit Home modules" · X.
- Left YOUR LAYOUT · 1 LARGE · 2 MEDIUM · 4 SMALL — slot map (L Objectives, M1 Up Next highlighted, M2 Pulse, S1–S4), drag/↑↓/Hide, presets Mission Control | Streamer/Social | Performance/Tuning.
- Right CATALOG · picking for selected slot — search, category tabs, Fits Medium, live previews.
- Footer: RESET TO DEFAULT · CANCEL · SAVE (yellow).

## layout-performance — Performance / Tuning preset
- L = PC LOADOUT 92% (temps, storage, RAM, RUN TUNE-UP) · M = Speeds over Game Mode ON · S = FPS / STORAGE FREE / AI USAGE / UPDATES · chips Fix stutter / Free storage / Update drivers / Check temps.

## layout-streamer — Streamer / Social preset
- L = CLIPS & CAPTURES · M = Squad over Pulse · For You · S = UPLOAD / PING / SENT TO CLOUD / DAILY DROP · chips Go-live / Find duo / Clip / Post ace.
