# GrokHub 2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Ship Waves 1–6 plus 2.0 A/B/C: skills, trust, dispatch, night shift, Presence (organs), and Cabin (this box is Grok’s third body).

**Architecture:** Extend the existing single agent loop (message → model → host/computer tools → memory/skill pins). New behavior lives in small `src/lib/*` modules with smoke tests; UI is chips, toasts, and Settings → Memory/Skills/Devices only. Skills and memory stay markdown files under `~/.config/GrokHub`.

**Tech Stack (superseded 2026-08-14):** the shipping product is native Rust (`crates/grokhub-app` → `grokhub`). `src/` and `desktop/` are deleted. This file is a historical Electron plan. New cabin work goes in Rust. See `docs/superpowers/specs/2026-08-14-rust-parity-design.md`.

## Global Constraints

- No new `NavId`. No Telegram/Discord/Slack/WhatsApp. No extra LLM providers. No WASM. No hook YAML. No multi-agent OS.
- Default autonomy stays level 1 (supervised). `/approve off` is labeled YOLO.
- Secrets never enter `MEMORY.md` / `SKILL.md` / daily notes. `redactSecrets` runs on host/computer output before the model.
- Bound project = world for host path checks. Unbound = full desktop.
- Session lock: one writer per `threadId`. Composer stays typable.
- Tests: `npm run test:unit` then `npm run typecheck`. No network in unit smokes.
- Follow `docs/superpowers/plans/2026-08-14-grokhub-2.0-workflow.md`.
- Spec: `docs/superpowers/specs/2026-08-14-competitor-takeaways-design.md`.
