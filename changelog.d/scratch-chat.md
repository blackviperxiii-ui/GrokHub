- Chat: `/scratch` opens a scratch chat, marked "Scratch chat · no memory read or saved" above its messages. The model gets none of your memory in it: no recalled notes, no SOUL.md or USER.md, no Know me tags, and no past desktop lessons. Its file tools can't open a MEMORY.md, and search skips every MEMORY.md. Nothing said in it is saved to memory: no flush notes at compaction, no `/remember`, `/learn`, `/dream`, `/forget` or `/memory prune`, no Reflect, and no MEMORY.md edits from its file tools. It also saves no task outcomes, taste notes, repeated-ask offers, goals, desktop lessons or routing lessons. `/bg`, `/send` and `/consult` started from it run as scratch too. The chat itself is still saved in History, and it stays a scratch chat when you reopen it. One gap: a shell command the model runs there, once you approve it, can still read or change a MEMORY.md.
