- Chat: an edit to a source file now counts as checked only after a command that runs, such as a test, build or lint run, or running the changed file. A re-read, `git status`, `git diff` or `cat` no longer clears it, and `cargo test 2>&1 | tail -20` or `npm test > /dev/null` still counts as a run. Every unchecked change is listed by its full path, not only the newest one, and a re-read must name the same file, not just a file with the same name.
