- Chat: an edit to a source file now counts as checked only after a command that runs, such as a test, build or lint run, or running the changed file. A re-read, `git status`, `git diff`, a viewer such as `cat`, `sed -n`, `Get-Content` or `echo`, or a test word inside a commit message, a grep pattern or a here-document no longer clears it. `cargo test 2>&1 | tail -20`, `npm test > /dev/null` and `make > build.log` still count as a run; `cargo test | grep -i fail` is no longer read as a change. Every unchecked change is listed by its full path, not only the newest one, and a re-read must name the same file, not just a file with the same name.
