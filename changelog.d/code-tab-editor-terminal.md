- The Code tab has an editor and a terminal on the desktop app. The editor opens and saves text files inside the project only (no `..`, no symlinks that lead out, nothing in `.git`), and each save goes in the tab's activity log. The terminal is your own shell in the project folder, with your project's secret values and common tokens hidden in what it shows; it keeps running while you're on another tab and ends with Close terminal or when the app quits. Neither works over the web app. Commands typed in the terminal, `git push` included, aren't checked by the push guard.
