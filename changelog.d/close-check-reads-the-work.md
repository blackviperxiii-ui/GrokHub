- Chat: the finish check that runs before a multi-step turn ends now reads what the turn did, not only its reply: the files it wrote, its last eight commands with their exit codes, its last test run, and its subagent and connector calls. A command moved to the background shows the exit code a later read of its task reported, or "still running"; a refused command shows as not run and never hides an earlier test run; passwords, keys and personal details are masked. A subagent shows whether it was done, partial, stopped, failed or is still running, a refused background command shows as not run, a line inside one task's output is never read as another task's status, and a compacted result keeps the exit code, task id and status lines it had. A reply that says "Updated the handler." with no write behind it, or after a failing test, now reads as not done.
