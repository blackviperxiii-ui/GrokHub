- Home on Linux: the Frame Rate tile now shows the frames your screen actually shows, counted by the kernel's display driver from outside the game, so anti-cheat has nothing to see. Reading that counter needs a setup run with sudo. The tile's Copy setup button gives you the commands: they copy Loadout to a small frame probe that only your user group can run, grant that one file the kernel's perf-counter permission (CAP_PERFMON), and make only the one tracepoint id readable. The system-wide perf setting stays as it is. Read the commands before you run them; the tile's hover text has the undo. Without the setup, the tile says plainly that it isn't reading.
