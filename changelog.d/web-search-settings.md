- Settings → AI models → Web search: pick free DuckDuckGo Lite (the default), your own SearXNG server, or Brave Search with an API key kept in your keyring. The next search uses the choice. The SearXNG server can be on the internet, this computer or your home network: give a server at home by its local name or IP address. Only that saved server is reached on your network; web pages and other searches still reach public addresses only. An address that can't be a server (like 169.254.169.254) is refused with a plain reason.
