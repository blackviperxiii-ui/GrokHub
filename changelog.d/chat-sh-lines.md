- Chat: `/sh <line>` and `$ <line>` run one shell line in the project folder, on this computer only. The line takes the Command page's checks first: forbidden lines, lines that reach outside the project and force pushes don't run. A first run asks on a card, a destructive line or one with a key or token in it asks every time, and a line you said yes to goes straight on next time. Run on the card checks the line again; typing a line can't stand in for it. The agent then runs it with the usual approvals, and the chat shows `$ <line>`, also when the chat is reopened. Lines sent from the Command page show the same way.
