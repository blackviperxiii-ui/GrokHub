- New opt-in Steady effort setting (Settings → Behavior, off by default). When it's on, a failed tool step no longer raises reasoning effort right away: effort goes up only after two failed tool steps in a row, chat stays at High or below, and the next clean step brings it back down a level. A run that hits a few missing files or unknown commands then spends less on thinking. Turned off, effort behaves exactly as before. The efficiency bench has a new `tool-errors` scenario that shows the effort of each request in both modes.
