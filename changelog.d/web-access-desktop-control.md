- Web access: a run that starts from a paired browser's words never gets desktop control. That covers a browser's chat, its Run now, an automation or a Workboard card a browser adds or edits (a card already in the queue included), and everything those runs start or write: helpers, routine steps (a saved routine run from a browser's chat included), and any job or card they create or rewrite, so a browser's job can't pass its words to a job made on the computer. Words made from a browser's words are a browser's too: a job you make recurring on the computer from a card whose title a browser wrote, and the Follow up card a browser's job files (its name and its run's report). Save a job's or a card's words again on the computer to give it back (saving a card's words or steps also replaces the goal and next step a browser wrote with them, and a report a browser's run filed stays a browser's until a run of your words files the next one; a job whose check command a browser's words set gets it back once the words you save say the check too, like ``check `df -h` ``). A job you saved again keeps desktop control when its run adds what its check command printed or what its wait found. A browser's edit that lands while you save keeps its words without desktop control. Say on a card runs without desktop control while that card, any card linked to its chat, or the automation it reports on holds a browser's words. A chat a browser started, or one a browser's job or card ran in, stays a browser's after a restart and however many chats come after it, so a message typed in it on the computer gets no desktop control either.
- Turning desktop control off now stops a running automation's next desktop step, a look at the screen included, in the app and in the background service.
- Web access: a paired browser can no longer pick up a chat the computer's window started after it is closed there. In a browser's chat, and in every run that starts from a browser's words (a `/consult` a browser sends included), the chat search tool finds and reads only chats a browser started, and the browser's Agents page and Reflect show only those chats.
