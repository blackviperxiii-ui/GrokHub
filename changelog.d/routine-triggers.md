- Routines can start on their own: on a timer (`daily 09:00`, `weekdays 07:30`, `every 15m`), when a file lands in or changes in a folder you name, or from a webhook by its name. Turning one on never fires it for the past or for files already there. In chat, the assistant can run a routine for you with the new `run_routine` tool, which shows only once you have a routine marked for chat; for now, a step that changes something is refused there.
