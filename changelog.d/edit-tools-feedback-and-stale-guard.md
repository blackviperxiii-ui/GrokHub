- Agent edits: `search_replace` answers with the changed lines numbered (three lines of context, at most three windows), a miss shows the closest lines, and a string found more than once names its lines. `write` and `search_replace` now refuse a file that changed on disk since the chat last read or wrote it, so an edit never lands on text the model has not seen. An edit after `cargo fmt`, `git checkout`, `/rewind` or a helper merge now costs one refusal and a re-read; a PostToolUse formatter hook does not.
